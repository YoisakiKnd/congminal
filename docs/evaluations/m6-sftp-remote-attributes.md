# SFTP 缺失远端属性的后台补全

状态：测试候选补上“所选文件属性不完整 → 后台认证/LSTAT → 完整版本 → 路径审阅/下载”。默认发布入口仍关闭，完整 M6 不勾选。没有新增 Cargo 包、工作器、并发槽或常驻进程。[最终证据审计](m6-sftp-remote-attributes-audit.json)核对当前源码、工具、清单、夹具及全部验收结果。

## 只读查询与版本

[Service](../../src/sftp/service.rs)新增 InspectRemote / RemoteVersion，复用原 2 工作器/64 等待/16MiB 子池。UI 只复制绝对原路径、所选属性、会话/Profiles 快照与票据，不打开文件或访问网络。排队阶段不创建 Backend；开始后才使用现有严格主机校验、私有认证 IPC/helper/OpenSSH 独立连接。

[协议操作](../../src/sftp/operations.rs)只发 LSTAT，不用会跟随链接的 STAT，也不打开数据句柄或目标。返回必须包含普通文件类型、大小和秒级 mtime；仍不完整或实际为符号链接/目录/特殊节点时拒绝。列表省略类型、或 permissions 只有权限位且未含类型位时允许查询；已经明确为非普通节点的列表选择提前拒绝。

查询复核列表已有的大小/mtime，已知字段变化返回 Changed，不把新版本悄悄套到旧选择。列表缺失的字段以查询时版本为准；查询到下载开始之间仍使用既有重新核对。SFTP v3 的 size/秒级mtime不是 inode 或内容哈希，相同大小/同秒替换仍可能不可见。

只在连接/端点明确回收后提供版本。协议/连接失败、取消、额度不足、清理失败都不能变成可开始的版本；只读任务结束时解释取消，保留原执行器回收契约。

## 一个表单、一个查询

[路径表单](../../src/workspace/transfer_paths.rs)冻结原名字节、已知属性并保留单个查询 Ticket/Authentication/固定错误。完整列表属性直接复用原流程，不额外发查询。缺失时可以继续填写 16KiB 本地目标，但下一步按钮未启用，Enter 也不能进入审阅。

查询认证优先，使用原受保护输入所有权并暂停表单；认证结束后用新 view 恢复，已提交的目标文字保留，组合/旧粘贴/旧输入丢弃。成功只更新同一查询票据；清理未确认、旧票据、终态错误后的重复结果都不能开启新表单。换窗格/配置、取消、输入代次耗尽及窗口关闭会按票据取消查询；迟到结果不会生成下载。失败停留在固定错误状态，不每 tick 重试；当前需要取消后刷新/重新选择，显式重试继续待办。

## 验证与成本

[15 项构建/静态/MSRV检查](m6-sftp-remote-attributes-build.json)通过：默认 debug/release 各 502 项、36 忽略，原生各 511 项、38 忽略；主机默认/原生及 Linux/Windows 默认 all-target Clippy、Rust1.88 原生编译及实际 Service/执行器/工作区/认证测试，主程序/helper 构建。交叉静态检查不代表真机运行。新增 4 项常规测试覆盖部分版本字段/未知类型准入、非普通节点/路径拒绝、未确认清理不启用版本、目标保留、旧票据及终态过滤、失败不重试和配置更换。直接构造的状态机完成消息仍携带有预算的结果/信封票据，不作为真实后端验证。

[13 类工作区文件](m6-sftp-remote-attributes-real.json)从实际目录读取开始，故意删去缓存条目的类型/mtime，真实独立 LSTAT 补全；新增成功下载、认证取消、直接取消表单、已知大小变化及实际符号链接拒绝五场景。其余实际双向传输、审阅/覆盖、后台切换与版本检查继续通过，加上 [12 类目录/认证/退出](m6-sftp-remote-attributes-workspace.json)、[15 类 Service 文件](m6-sftp-remote-attributes-transfer.json)，共 40 类真实回环通过。它不是让服务端本身省略字段，也不是原生 GUI/IME/剪贴板或三平台运行证明。

直接取消表单时没有认证前端；如执行器已开始，则验证原 Ticket 的取消结果与 Confirmed 清理；如仍排队，则验证取消计数、无活动/等待/结果项，随后同样确认关闭/join。排队项由回收线程析构，可以不产生完成消息。最初夹具错误地只等待完成消息，[超时记录](m6-sftp-remote-attributes-real-queued-cancel.json)保留，修正后本次实际观察到 running_result；排队项回收行为另由[执行器队列取消测试](../../src/sftp/executor.rs)的64项取消验收，不能把本次场景当成同时观察到两种调度时序。另保留 [Windows 夹具条件修复前检查](m6-sftp-remote-attributes-build-windows-fixture.json)。

[当前/Rust1.88 各 5 项本地子系统互操作](m6-sftp-remote-attributes-local.json)通过，新增实际普通文件属性及符号链接类型断言，证明使用 LSTAT 取得节点本身类型。

## 条件性查询的实测成本

[五组交替配对](m6-sftp-remote-attributes-cost.json)使用同一 release 夹具、服务端、加密密钥及 32MiB 内容下载；各两次预热，保留全部 14 次原始试验。基线保留完整缓存属性，查询组移除类型/mtime，因此多一次实际认证连接和 LSTAT；缓存输入条件及场景目录名长度不同。这是缺失字段分支的完整流程增量，不是同输入后端替换，也不作为“≤5%”采用门槛。

完整受采样进程流程的配对耗时中位增加 **174.291ms / 32.53%**，五组范围 161.824～189.878ms / 29.86～35.76%。两组各自耗时中位约 533.556 / 710.009ms；不能用两组中位数相除代替配对中位。计时从 Popen 返回后至进程结束/输出处理，包含测试框架、准备源文件、软件界面强制绘制、模拟即时认证、已有本地 cat PTY、IO/字节核对和关闭；不是单次查询延迟或原生输入延迟。

客户端/自建服务端进程树单独采样。配对 CPU 观察下界中位增加 141.438 / 6.999ms，范围 131.776～150.358 / 1.118～14.428ms；客户端观察到的 RSS 峰值配对中位 +176KiB（−144～+480KiB），服务端 0KiB（−16～0KiB）。客户端进程峰值基线均 6、查询组 6～7，服务端均 4；这些包括夹具、本地 PTY、OpenSSH/helper，不能只计算主程序或将短进程成本忽略。采样可能漏掉边缘/短进程及峰值，RSS 求和可能重复共享页，观察器 CPU 不在两树中；软件强制绘制也不能代表实际 GUI 的 CPU 增量。

结论：保留按需补全的安全流程，完整属性路径不发额外查询；额外连接/认证的等待已量化，不能称为零成本。当前不复用查询和下载连接，连接复用、小文件/弱网与原生输入仍是发布前的优化和验收项。

## 额度与释放

[当前工作区计量](m6-sftp-remote-attributes-allocation.json)与 [Rust1.88](m6-sftp-remote-attributes-allocation-msrv.json)包含实际 InspectRemote 请求在不存在端点父目录处失败、16KiB 本地目标/1023字节预编辑及错误表单；不创建 socket/SSH，该夹具不证明真实网络流的全部分配。查询阶段请求 live 为 1053960 / 1054369 B、peak 为 1076008 / 1076417 B，子用量 5039504 B、输入用量 19343 B。200 次预热错误表单直接绘制零分配/扩容。

完整夹具继续包含最大上传表单、实际本地源检查、66条小路径记录、最大双路径审阅及合成认证/跨销毁旧输入，请求 peak 为 1951082 / 1951491 B，最后新增请求和 SFTP 父预留均零。其他表单/审阅各 200 次预热直接绘制也不分配；全夹具有 145 次 realloc，不能称全部帧零分配。root_total 最后仍有 1146880 B 其他资源。计量预热原画布/配置/首次线程初始化，计新线程/TLS与保守扩容重叠，排除计量头、allocator/C/ObjC/OS、实际栈/RSS；后续阶段包含前面新增的字体缓存，不能把差值都归到查询字段。

[文件当前](m6-sftp-remote-attributes-file-allocation.json)、[Rust1.88](m6-sftp-remote-attributes-file-allocation-msrv.json)仍在 13 项最大 DTO 后因输入额度拒绝；运行时预留 R=4941344、输入上限 Q=2398688、IO余量 H=9437184、总池 T=16777216 B 不变。输入2291640 B、实填 IO 后子用量16670168 B，请求peak11734113 / 11734522 B，父票据覆盖，最后 Status 释放归零。

查询需要额外的连接、认证和只读往返，不能称为零性能影响。完整目录属性不走此分支；缺失属性时复用池并让 UI 保持事件驱动，避免在界面线程等待。请求/身份/表单仍受原输入和总额度约束，结果只含固定 Version，没有扩大缓存。全局内存准入、真实 GUI P95/P99、弱网/小文件、30分钟时序与其他平台仍待验收。
