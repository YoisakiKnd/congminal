# M4 整形索引及点阵字符映射

零新增 Cargo 依赖、线程、子进程或 unsafe。GSUB 查找与覆盖位图按实际请求容量准入，随整形器持有原字体账本；4096 个候选查找先在固定栈缓冲中排序去重，保留 256 个查找及既有工作量上限。位图复用一个固定数组，只清理上一查找使用的前缀，不把整块数组逐次返回/复制。GSUB 上下文/替换临时数组及 morx 64 项组件栈改为固定栈空间，保留嵌套深度边界。

编程连字的 glyph 工作数组预先覆盖最多 256 个扩展结果或原长输入；结果和原文先准入再生成，原子交给缓存。缓存改用 u64 指纹定位，仍逐字验证原文；碰撞只替换缓存，不能串用结果。返回借用的结果切片，命中不克隆输出、不更新额度。emoji 临时字符串与 256 项 glyph 序列预先准入，整形器槽 Vec 精确保留容量并持有票据。

PSF 的 BMP 映射一次准入 128 KiB，销毁后归还；不足时借用静态原表查询，不因内置字体映射被拒而 panic。损坏 UTF-8 不生成临时替代字符串；尺寸/乘法/字形数/总字节边界先验证。低额度查询较慢，像素生成先申请额度、成功后才查字符。

初轮发现整形索引生成 7.382→35.441 µs、热连字七词 1.336→2.372 µs；保留 [初轮数据](m4-shaper-workload-initial.json)。分别消除整块数组搬迁及长字符串重复哈希后重新冻结源码、完成检查并重测，不把初轮作为通过结果。

最终五组交替前后对照，固定 Maple Mono NF CN Regular/Apple Color Emoji/内置 Terminus，输出校验值逐项相同。字体初始化在探针/计时外，探针与无探针计时分别构建。

GSUB 请求峰值包括调用方 512 B glyph 测试输入；新索引本身 6,524 B 准入，调用方输入不由该整形器票据持有。冷连字请求持有量 2,732→1,438 B，完整工作集峰值下降约 64%，热命中不分配。emoji 的槽常驻容量 352→112 B；新计费准确覆盖该路径 14,934 B 峰值，不把全部票据都当临时内存。

索引构建增约 0.484 µs（6.3%）、PSF 充分额度解析增约 0.186 µs（13.3%）；不宣称零成本。零额度借表查询增至约 0.895 µs，只是低额度降级，正常密集映射仍约 11–12 ns。PSF 两个小头部保留内联，避免低额度路径再分配 Box；像素与映射保持堆外置。

完整五组 CPU 基准：VT 130.8→130.7 MiB/s，输入 P95 250→250 ns，工作区输入 P95 333→333 ns；四窗格整帧 608→607 µs，局部帧 26→26 µs。十组独立整帧 3.030→3.023 ms，单行 0.316→0.311 ms。本机性能门槛没有用隐藏慢样本或提高预算规避；不包含真实窗口端到端延迟。

Debug/release 各 294 通过、13 显式忽略，另显式运行本机 Maple Mono 编程连字回归；三平台 all-target Clippy `-D warnings`、格式及 release 构建通过。独立夹具覆盖 GSUB 精确索引准入、低额度拒绝、字号所属拥有者释放、Coverage 复用前缀清理、指纹碰撞原文验证、借用结果指针、PSF 全部内置已映射字符及缺字的密集/借表一致性、无效几何与 UTF-8。
