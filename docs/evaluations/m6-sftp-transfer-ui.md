## 审阅与提交

[审阅组件](../../src/workspace/transfer_review.rs)捕获Profiles/索引、会话/逻辑代次、原名字节路径、数据长度或下载Version，文本显示完整配置请求目标及转义后的源/目标。配置别名、继承的用户/端口保留明确说明，不把请求别名冒充解析后的地址；实际主机密钥验证继续交由独立SSH通道。这里没有冻结或完整展开全部系统SSH配置的内容。

审阅只有一份，文本与行索引先在同一子池的SftpInput分类准入。两条路径各最多16KiB、显示最多四倍展开，输入拒绝不启动文件任务。文字只读；原名字节用于提交，不从显示文本反解，也不发送到PTY。构造/审阅阶段不访问文件、查询配置或网络。目录结果/文件选择器仍须在后续提供经过后台准备的长度/版本；当前上传保持既有“开始时打开并检查、传输期间再核对”的语义，没有新增选择时的本地文件版本保证。

行索引按最多1024字符、约500µs的合作式片段建立，最多160列/20行、单行128字符；使用预留容量，重新布局重用索引。实际绘制连续覆盖全部行后才允许提交，不能按End跳过中间页面。字体不能完整绘制、矩形裁剪、窗口太小、布局未完成或来源失效都不能取得开始许可；500µs不是硬实时保证。鼠标按下/抬起匹配审阅nonce和实际控件矩形，滚动/失焦/缩放/重新布局会退役旧点击。Enter/Esc关闭，只有可见开始控件可以提交。

默认不覆盖，即使内部调用方提供ExplicitlyApproved也不会自动勾选。点击覆盖复选框后清空已审阅覆盖范围并回到开头，需要重新查看及点击“确认覆盖并传输”。准入失败保留原审阅，提示未开始，不循环重试。普通文字、预编辑和粘贴在只读面板内被消费；不回落终端或认证答案，窗口关闭仍走共享退出门禁。

已结束或旧配置的报告可按原绑定打开只读快照，包括完整源/目标、发布/清理状态及部分文件候选；报告没有覆盖/开始按钮。候选名不保证文件存在，报告不是删除或自动续传授权。

## 固定列表与进度

[右栏列表](../../src/workspace/transfer_list.rs)复用原66条受管文件记录，显示方向、发布/失败/不确定状态、字节与最近采样平均速度，支持选择、取消、明确清除和完整详情。清除只释放内存，不删除文件。行与工具栏点击绑定实际绘制的Ticket、渲染代次和矩形；删除、重排、模态切换或迟到抬起不能把操作套到新任务。

已发布但回收失败、提交不确定、已请求取消、未开始等语义分开，不能把取消请求当作撤销已发布文件。列表上的短行可能裁剪，完整信息通过详情审阅。详情是打开时的快照，不是持续刷新的第二份任务状态。

只有列表可见、没有审阅覆盖层且有活动记录时，每250ms合并读取一次固定快照；速度按两次采样的字节差/实际时间计算，不是瞬时网速。没有每数据块UI消息、新线程或无界事件队列。隐藏、服务关闭、没有任务或全部结束后不保留这个进度期限；已结束记录使用完成时的快照。这个机制的原生CPU/唤醒、输入P95/P99与绘制成本仍需在完整程序做同负载验收。
