# SFTP 实际预览入口与发布边界

2026-10-25。实现了显式编译、配置、入口和 helper 发现，并生成独立 macOS arm64 实验包。**原生窗口认证/传输未通过验收，不标记 M6 完成或替代普通 Alpha.6。** 本轮有软件前端的真实协议证据，也保留原生尝试未通过的记录，两者不能混用。

## 实现与默认成本

`sftp-preview` 开关将原来的目录/传输、保护输入、通知和退出候选接入主程序；不默认启用，不添加 Rust 包。普通构建仍无 SFTP 工作器或 helper。原生库 `sftp-libssh2` 候选及其解析器继续只在测试编译，不因同时选择 feature 意外进入实际后端。

配置 `[sftp] enabled=true` 后，活动 SSH 会话的文件页显示“连接 SFTP”；点击前没有池、工作器、helper 或 SSH 连接，也不把远端会话静默回落成本地文件浏览。入口校验当前会话、渲染代次、几何、前台焦点和完整可见的按钮。连接后复用原目录、路径输入、源检查、完整审阅、任务/通知和关闭门禁。

默认 helper 在实际主程序旁查找，包内与主程序同目录；可显式指定绝对路径。`ssh-config` 未指定时沿用系统 OpenSSH 配置。两个路径分别限 4096 字节、拒绝 NUL 和相对路径，写错时停用入口，不回落到另一份配置。UI 不检查文件是否存在；工作器创建实际后端后返回失败。配置不含密码/私钥正文。helper/SSH 配置被池捕获后不热替换，更改后需重启。

启动时未连接只有额外程序代码及固定入口状态；配置路径最多两份各 4 KiB。入口构造临时路径前预留 17,408 B，创建后由原 Options/请求分别持有额度。连接才创建 16 MiB 子池、2 工作器、1 回收线程及按需临时 SSH/helper 进程；子池不包含子进程 RSS，也不是全部应用堆上限。此处的配置/工作区固定元数据仍属于 M4 全局账本剩余范围，不宣称完整计费已完成。

## 验证

- [构建/回归](m6-sftp-preview-entry-build.json)：普通 516 项通过、36 专用测试忽略；预览 519 项主程序及 18 项 helper 通过、37 专用测试忽略。三目标静态检查及组合 feature Clippy 通过；Rust 1.88 工作区 35 项通过、3 专用测试忽略。格式、脚本语法通过。跨编译不等于真机。
- [实际入口真实回环](m6-sftp-preview-entry-real.json)：解析显式配置、实际绘制/点击入口、独立认证、服务端固定夹具目录、源输入/检查、完整审阅、上传/下载逐字节核对、join 及 SFTP 父额度归零均通过。共 3 次生成密钥的认证提示；只使用隔离配置，没有用户 SSH 文件。焦点由测试提供，PTY 为本地 cat，并非原生窗口或真实 SSH 终端的组合验收。
- [资源回归](m6-sftp-preview-entry-allocation.json)：既有工作区的路径/查询/重试/66 记录/通知/退出/认证及迟到输入探针继续通过，峰值 Rust 请求 1,954,698 B，最终请求和 SFTP 父预留归零，其他应用分项仍为 1,146,880 B。该探针按原方式编译测试，不包含预览入口临时构造或配置加载，不能作为新入口全线程分配、原生 GUI 延迟或完整 RSS 上限的证据。
- [包验证](m6-sftp-preview-entry-package.json)：版本显示 `(SFTP preview)`，包含 helper，主程序与 helper 的本机临时签名、ZIP 解压和版本检查通过。依赖树无 Rust 第三方包，主程序/助手仅链接系统库。原始主程序 2,709,968 B、helper 568,784 B，ZIP 1,281,181 B；文件大小不表示常驻内存成本。
- [记录核对](m6-sftp-preview-entry-audit.json)：构建、真实回环、原有分配夹具与当前源码/工具一致。

共享认证/协议源码同时供主程序、helper 和互操作验收使用；生产子集允许未使用接口的 dead-code 提示，测试仍完整检查。预算与认证/焦点门禁保持原设置。

测试 app、主机已停止，生成私钥已移除，对应临时路径未发现残留进程。没有修改用户配置。没有放松前台焦点/旧输入门禁，未把显式焦点的软件回环当作原生验收。首次目标文件名建议未被替换导致的夹具失败，以及组合 feature 意外编译测试库后端导致的编译失败，也各有独立历史 JSON 保留，修正后再取得最终证据。
