# M4 轮廓与字形光栅化准入

零新增依赖、线程及子进程。TrueType 简单/复合字形的线段、解析临时数组、realloc 新旧块重叠、光栅化浮点面积与 alpha、伪粗体像素交接、COLR 图层索引/临时位图/合成输出、内置点阵生成像素接入共享额度。按原字体拥有者计费；临时结果把已有像素额度原子交给缓存，无每个持久 Glyph 票据。

解析错误或额度不足返回失败，保留先前缓存；COLR 不因某层准入失败而展示缺层结果。空图层可跳过，整张合成工作集失败后释放所有临时图层。伪粗体先覆盖旧、新 alpha 同时存活的峰值，拒绝时原像素/尺寸不变。彩色字号选择不再收集临时 Vec，保留原有同尺寸选择顺序。点阵输出一次精确分配，避免 flat_map collect 的增长。

构造的独立 TrueType/COLR 输入验证正常像素、拒绝完整工作集、复合输出增长、所属账本及回收；系统字体另作前后性能对照，不把系统字体用例替代独立格式回归。Debug/release 各 288 通过、13 显式忽略；三平台 all-target Clippy `-D warnings`、格式和 release 构建通过。

探针/计时分开构建，字体加载及点阵字符映射构造在测量前；七条路径的尺寸、偏移和全图校验值一致。逐组请求字节峰值均被准入峰值覆盖，最终输出销毁后归还额度。仅计 Rust 请求容量，非分配器实际占用或 RSS。

五组交替样本；新轮廓按简单字形的点数保守预留输出容量，所以 A/é 峰值增加 168/728 B，é 增约 21%。大字形峰值几乎不变；不把准入本身说成内存下降。两层合成和 PNG emoji 中位耗时约增 1.0%/0.4%，含额度处理。保留每组原始波动，不仅报告较快样本。

整套基准五组：VT 130.3→130.8 MiB/s，输入 P95 250→250 ns，四窗格整帧 597→603 µs、局部帧 25→25 µs。十组独立预热整帧 2.991→3.027 ms（+1.2%）、单行 0.308→0.312 ms（+1.1%）。同组硬行重排 P95 238→264 µs，源码未变，未把波动归因于轮廓准入；仍小于 500 µs 合作式目标。这些 CPU 基准不包含原生窗口输入到呈现。

原始证据：[字形分配与计时](m4-raster-glyph.json)、[整套基准](m4-raster-bench.json)、[独立帧](m4-raster-render-isolated.json)、[构建和源码摘要](m4-raster-build.json)。探针覆盖的是上述生成路径；GSUB 整形索引/临时序列、PSF 字符映射、字体发现、缓存桶及任务元数据仍需补齐，完整账本尚未完成。
