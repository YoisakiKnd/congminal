# M4 持久历史计费与压力回收评估

日期：2026-10-21。当前工作区未提交、未发布；基线为本轮开始的本地快照 `/tmp/congminal-history-baseline-01a158a4`，已含上一轮 UI 分片重排，并非远端 alpha.5。没有新增 Cargo 包、生产线程或周期采样。源码指纹及验证记录见 [构建记录](m4-history-build.json)，机制见 [资源说明](../execution-m4-memory.md)。

## 完成范围

持久历史 cell 容量及完整行索引容量接入共享账本，每个历史一张汇总票据，普通增长按 64 KiB 聚合，低额度时尝试精确申请。空闲索引槽继续计费，稳定满额滚动轮换已有行；压力解除后在解析批次边界恢复增长。未新增逐 cell、逐字节或稳定逐行滚动的全局锁。

同步重排连同输入索引转移原票据；只读 UI 源继续保有票据。临时工作集向输出历史原子转移额度，不在满账本中二次申请，也不先释放再争抢。取出行尚在转移期间保留额度，销毁后才收缩。接管输出后仍可能有屏幕行推进历史，工作集余量须保留到该步骤结束。

压力先清缓存，再分片回收未选中会话的最旧历史，包括未选中的可见分屏；跳过当前选中会话及重排作业。约 500 µs 合作式 tick 预算、每会话 4096 cell 工作量，固定上限元数据和单行/分配器调用不可抢占。回收更新 revision、滚动位置、命令与链接；搜索/复制据版本失效。无可回收对象时停止即时唤醒，不自动重放被拒绝的新建/缩放动作。

Debug/release 各 **263 项通过、13 项手动基准忽略**；macOS 本机、Linux x86_64 GNU 和 Windows x86_64 GNU 的 all-targets Clippy `-D warnings` 通过。新增测试覆盖实际 cell/空闲索引计费、暂存行不提前归还、输入与票据共同转移、满账本内部转移、低额度连续一万次滚动不增加拒绝尝试、压力解除后恢复增长，以及非活动历史分片回收、选中源保护、重排源等待与无工作时停止唤醒。原有参考重排差分、取消及销毁归零测试继续通过。交叉检查不等于三平台真机验收。

最终 release（debug=1）二进制 1,912,712 → 1,913,496 字节，增加 784 字节；不是启动成本验收。

## 分配探针与计费含义

测试副本注入线程局部 GlobalAlloc/System 请求字节计数；realloc 计旧新重叠，不是 usable-size 或 RSS。九种形态全部通过额外峰值不超过准入余量、最终网格容量受预留覆盖及最终额度归零的断言。原始代码和全部样本见 [分配记录](m4-history-allocation-probe.json)。

| 场景 | 额外存活请求峰值 MiB | 本次额外准入 MiB |
|---|---:|---:|
| 64 MiB 硬行缩窄 | 67.78 | 138.38 |
| 64 MiB 硬行扩宽 | 67.80 | 138.27 |
| 64 MiB 长软行 | 71.06 | 145.05 |
| 窄历史扩到 4096 列 | 64.57 | 131.67 |
| 2048 行先扩到 4096 列再缩到 1 行，同步路径 | 160.09 | 321.14 |

额外准入减少主要是旧历史已由持久票据覆盖，不再重复准入输入；**这不是实际复制峰值降低**。长软行仍额外约 71.06 MiB，上一轮同形态的同步消费约 8.88 MiB；只读策略的内存与完成成本问题继续保留。旧工作区 64 MiB 池按有效行描述符计费，共享账本另外包含全部空闲索引槽，不能将两者相加或把历史池解释为全部堆上限。

## 剩余边界

完整共享计费还缺字体解析/光栅化/解码临时缓冲、缓存桶、布局/搜索/通知与任务元数据等。512 MiB 仍是已接项目的混合额度，不是完整堆或 RSS 上限。小网格、高度变化、备用屏、画布分配及关闭 Session 析构仍有同步工作；只读重排峰值、真实窗口延迟、启动、三平台真机及 30 分钟长测继续列在 [计划](../roadmap.md) 中。
