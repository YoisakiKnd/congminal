# SFTP 本地上传源选择

2026-10-25。工作区源码已加入本地文件选择器，限显式 Unix `sftp-preview` 入口；默认发布包不启用 SFTP。此前提供的实验 ZIP 是旧快照，尚不包含本轮选择器。完整 M6、原生窗口传输和三平台验收继续保留未完成。

上传表单可以“浏览本地”，进入目录、返回上级、切换隐藏文件、刷新，选中普通文件后返回。列表保留原始 `OsString`，选定路径不经过 UTF-8 往返；控制字符、反斜线、双向控制和非法 UTF-8 在显示层转义。左栏本地目录也复用该显示规则。非 UTF-8 源名不会自动生成有损目标名，需要输入目标名或使用已选远端目标。列表里的符号链接不进入，也不能选作上传源。

选择不会打开文件内容或创建传输任务。返回后仍通过后台源身份/大小检查，再进入完整主机、源和目标审阅；默认不覆盖，既有源版本/提交检查保持不变。路径输入与原字节选择之间可显式切换。选择器打开、关闭、导航、焦点或布局变化均撤销旧输入及点击身份；迟到结果校验任务、绑定会话和配置代次，不回落到终端输入。

## 资源与并发

共用原 Service 的 2 个工作器、64 个等待槽及 16 MiB 子池，不另建目录线程、helper 或 SSH 连接。目录操作在建立传输连接之前分流，只读目录项及类型。抽出的 `src/local_directory.rs` 同时供左栏使用，仍为最多 512 项、扫描 8192 项、16 KiB 路径、1024 字节名字和 3 MiB 工作预留；满额明确标记列表不完整。显示名按最多四倍原字节预留。请求和保留结果持有同一子池额度，拒绝后等待显式刷新，不自动循环重试。

选择器固定 36 个点击槽；绘制只访问可见行，最多 31 行，不复制完整目录。固定工作区结构与初始画布在本轮探针之前已创建，仍属于 M4 完整元数据账本的剩余范围，不能把结果当成整个 UI 堆上限。

目录后端目前复用 `std::fs::read_dir`，在各项之间检查取消，以 RAII 释放迭代器。不能证明正在阻塞的文件系统调用会立即被中止，或把迭代器析构视为已观测到 OS 关闭错误；慢盘、挂载文件系统及退出等待仍需补验和适配。这一限制同样适用于既有本地目录后台读取。没有因此降低关闭 join 或焦点门禁。
