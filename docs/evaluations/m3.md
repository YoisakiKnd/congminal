# M3 本机评估

日期：2026-10-20。平台：macOS arm64，本机 Rust 1.99.0，offline release 构建；功能和边界见 [执行记录](../execution-m3.md)。

## 选择与结论

语义解析、命令标记、分片复制和通知中心使用现有模块及标准库自写适配，新增 Cargo 依赖为零。它们不启动新的常驻轮询器。Shell 脚本为可选 source，标准控制序列支持不要求用户安装运行时。

系统通知采用默认关闭的工具适配原型：系统 osascript、可选 notify-send、Windows PowerShell/.NET NotifyIcon。这些工具确实可能产生进程启动、外部 RSS、IPC 和权限成本，本机没有完成真实送达/外部峰值验证，所以**没有把它们纳入默认功能或宣称为零开销**。工具无须随本程序打包，应用不自动安装依赖；找不到工具或调用失败在中心反馈。后续若要默认开启，必须按 [依赖政策](../dependency-policy.md) 补全版本、平台、峰值与 30 分钟数据，或替换为经测量的原生适配。

当前五轮同负载对照未发现稳定的 VT/绘制/空闲资源回退超过门槛。GUI 启动存在明显的运行条件差异：固定顺序数据有约 7.6% 的中位数增加，配平路径和顺序后为约 4.1% 的下降，不能据此宣称启动零影响或已确定原因。保留所有启动样本，后续平台验收继续检查，而非只挑选有利的一组。

## 同负载基线

前置快照 `/tmp/congminal-m3-baseline-01a158a4` 保存本轮开工时全部跟踪/未跟踪源文件，已经包含 M1/M2；不拿旧 HEAD 代替当前基线。最终原始样本：[m3-bench.json](m3-bench.json)。前后各五轮交替运行；每轮输入 1000 个事件，P95/P99 由每轮排序分位数再取五轮中位数。输入只计应用事件处理至入队，不包含显示、操作系统输入法或 PTY echo 延迟。

| 指标 | M3 前 | M3 后 |
|---|---:|---:|
| VT 吞吐中位数 | 65.9 MiB/s | 66.1 MiB/s |
| 3616×2416 全帧中位数 | 6.952 ms | 6.803 ms |
| 单行更新中位数 | 0.663 ms | 0.668 ms |
| 输入处理 P95 | 208 ns | 167 ns |
| 输入处理 P99 | 2625 ns | 2292 ns |
| 64 MiB 历史搜索分片 P95 | 293 µs | 304 µs |
| 搜索总时间 | 50 ms | 50 ms |
| 搜索状态内存 | 33,422 B | 33,422 B |
| release 二进制，含 debug=1 | 1,564,744 B | 1,612,152 B |

二进制增加 47,408 B，约 3.0%。不同时间机器状态会影响绝对速度，使用同轮前后相对结果，不能把早期运行较快的数值和最终数值拼成一个“加速”结论。新状态模型只在 OSC/控制编辑边界维护索引；普通字符打印没有新增命令链表扫描。

新增负载每轮处理 100,000 条完整 OSC 133 命令及短输出，五轮中位数 66 ms，命令/事件元数据分配 90,240 B。新功能没有同等旧实现，因此该数据是任务成本，不是“比基线快”的证明。

1,920,000 B 输出复制分 117 片完成，五轮中位数：总时间 22 ms、片 P95 208 µs、片最大值的中位数 329 µs；所有轮观察到的最大片为 422 µs。复制缓冲高水位 2,097,152 B。上限/取消测试另验证超过 2 MiB 时拒绝复制，数据变化时取消，剪贴板不提交半份结果。约 2 ms 的时钟检查是合作式预算，操作系统调度可能造成墙钟超时，不能当作硬实时保证。

## 可选 zsh 脚本成本

[m3-shell-hooks.json](m3-shell-hooks.json)：本机 zsh 5.9，五轮交替，每轮 100 次 `:` 空命令；真实 PTY，关闭 zle，TERM=dumb 以识别单次提示符；相同目录。排除首次 source，统计写命令到收到下一次提示符的墙钟时间。只在采样结束后终止并回收本次测试 Shell。

| 指标 | 无集成 | 有集成 |
|---|---:|---:|
| P50 的五轮中位数 | 30.896 µs | 224.251 µs |
| P95 的五轮中位数 | 41.458 µs | 255.833 µs |
| P99 的五轮中位数 | 48.667 µs | 301.625 µs |

P95 增加约 0.214 ms，包含目录编码和发射控制序列，**并非无成本**。脚本不创建进程/常驻线程；复杂提示符、超长路径和 Bash 4.4+ 的成本未验证，本结果不外推到它们。真实 PTY 功能测试另使用正常 zsh 行编辑器覆盖 Ctrl+C、管道和既有 hook。

## GUI 启动与空闲

读取本机 `proc_pidinfo` 的 RSS、CPU 计数、线程，按正确 PID 数量读取子进程；以 spawn 到 Shell 写就绪标记计启动时间，不等于首帧呈现。Shell 标记之后 exec sleep，应用自然退出，非强制杀进程。

- [初始五轮](m3-runtime-initial.json)：启动中位数 238.64 → 254.12 ms；包含 1075.93/543.52 ms 的首次冷样本，期间存在编译/测试活动。全部保留。
- [隔离编译/压力的十轮](m3-runtime.json)：固定 before→after 顺序，启动 232.97 → 250.61 ms，约 +7.6%；RSS 115,269,632 → 115,318,784 B，线程均 14，唯一子进程仍是 Shell 的 sleep，没有通知进程；空闲单核 CPU 0.01371% → 0.01291%，子进程 0%。
- [配平顺序十二轮](m3-startup.json)：前后二进制复制到同级临时目录、相同文件名，交错 before→after / after→before，首次冷样本仍保留。启动中位数 398.86 → 382.53 ms，约 −4.1%；此轮 Shell 标记后立即退出，与上面的驻留模式不同，不能跨组直接比较绝对值。

这些结果支持“默认路径无新增后台通知进程，空闲资源接近”的结论。启动差异的归因尚未确定，不能只凭最终一组通过就抹掉前两组。系统通知启用后的外部工具 RSS/送达成本尚未通过采用门槛。

## 正确性与资源压力

- debug/release 正常测试各 **177 通过、7 个手动测试默认忽略**；fmt 和本机 clippy `-D warnings` 通过。
- Linux x86_64 / Windows GNU 的 all-targets clippy 通过，仅表示交叉编译检查，不是平台运行测试。
- 真实 zsh 5.9 PTY 验证重复 source、原有 hook、退出码 0/1/7、管道、Ctrl+C=130、中文及 ` ;#%` 路径、Shell 退出不产生虚假成功。Bash 3.2 明确拒绝安装并正常返回；Bash 4.4+ 只有语法/设计检查，运行验证待补。
- 其他测试覆盖 URI 及 OSC 容量、未知退出码、输入取消/提示符重画、重复完成、备用屏幕、resize/reflow、清屏/编辑、历史淘汰、复制失效/超限、通知容量/类别/静音/去重/速率和辅助进程缺失/失败/取消回收。
- GUI CI 冒烟启动、输出、自然退出通过。系统截图返回 `could not create image from display`；未取得截图视觉验收。另保存了真实 Renderer 的 [通知中心帧](../previews/m3-notifications.png)，检查了中文、选择高亮、通知条和空心终端光标。

压力原始时间序列：[m3-stress.json](m3-stress.json)，首次记录另保留 [m3-stress-initial.json](m3-stress-initial.json)。持续 75 秒，在约 64 MiB 历史上重复命令、通知、按片复制、选择、窗口重排和绘制；不是只观察空闲内存。历史始终不超过 64 MiB，通知和命令元数据有固定上限，默认没有系统通知任务。最终一轮 75.11 秒完成 372,394 轮，命令元数据 45,184 B、通知 4096 B 保持固定；线程始终 5 个。RSS 从采样时的 86.56 MiB 预热到约 251.36 MiB，最后约 253.14 MiB，55–75 秒未见继续增长。tick 墙钟最大观察值 71 µs（短输出复制场景）。

前一轮 375,877 轮的 RSS 在约 179.45 MiB 稳定，两轮高水位差异显著，原因尚未定位。该压力场景反复对整份历史重排，不能拿受管“64 MiB 历史”当作整个进程 RSS 上限，也不能把两轮稳定平台解释为已经证明全局预算或无泄漏。保留全部时间序列，M4 必须把重排临时缓冲/分配器高水位纳入全局准入及复用评估。

macOS 通知固定 AppleScript 在正常系统环境通过 osacompile（仅编译，未执行/发送通知），argv 传值回显验证通过。沙箱内加载 Standard Additions 术语时编译失败，解除沙箱的同源编译成功；本项不代表系统通知权限或实际送达通过。

30 分钟长测、真实通知权限/送达及工具峰值、Bash 4.4+、Windows/Linux 运行和三平台输入法仍为未完成验收项。当前本机短测不替代这些项目；系统工具继续默认关闭。
