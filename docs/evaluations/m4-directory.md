# M4 本地目录侧栏

使用标准库和现有单槽后台任务，零新依赖/子进程/unsafe。默认会话页不创建目录线程或读取目录；首次打开文件页后复用一个条件变量等待的工作线程，限制一项运行、一项最新待处理及一个结果。系统文件调用无法强制取消；复用该槽避免反复开关积累线程。隐藏/切换会话立即清理 UI 并失效旧结果，后台在系统调用返回后合作式取消，不在 UI join。

仅目录项及类型，不读正文、不解析 shell 输出、不执行文件名、不跟随链接。目录优先/native 名排序，保留原名、显示控制字符替换；上级/刷新/隐藏/滚动及文件选择均保持终端输入焦点。起点为配置工作目录或启动目录，不跟随 OSC 7，不保存目录位置。单次最多 512 项/8192 次扫描，达到上限明确标记可能不完整；路径 16 KiB、名 1024 编码字节，失败保留受管目标供显式重试，不忙循环。

`directory-reserved` 在请求路径分配前计费，扫描前预留 3 MiB，返回按实际容量缩减；名字、显示名、列表索引/路径/摘要均归属票据，先销毁数据再归还。512 项长名在本机常见文件名长度内测量；3 MiB 是保守工作额度，可能在剩余额度不足时拒绝扫描，并非实际每次分配 3 MiB。工作线程及 libc read_dir 内部未完整计入，仍不作完整堆/RSS 承诺。

临时副本注入分配器，只统计 Rust 请求字节，含 realloc 旧新重叠；计时使用另一无探针构建，五轮、热文件系统、扫描及销毁，不与其他性能工作并行。全部样本实际峰值被准入覆盖；销毁后实际请求及额度均为零。

功能关闭的五组交替前后基准：整帧 3.159→3.052 ms，四窗格 651→629 µs，工作区输入 P95 291→291 ns，P99 2584→2209 ns；原终端输入 P95 209→292 ns。十组独立帧 3.080→3.099 ms（约 +0.6%），单行 0.317→0.323 ms。整套中的重排 P95 297→408 µs、总耗时 5→6 ms 有波动，该内核未改；保留原始数据，不将通用基准差异解释为目录功能的加速或 UI 延迟验收。原生窗口呈现和目录扫描并发负载仍待进一步测量。

Debug/release 各 306 通过、13 忽略；三平台 all-target Clippy `-D warnings`。覆盖配额、取消、owner 换代/迟到结果、失败目标重试、隐藏文件扫描上限、控制字符/符号链接、原生路径、分数滚动，以及真实 Workspace/PTY 导航不注入终端输入、切换及窄窗释放。实际 Renderer 画面经检查见 [预览](../previews/m4-files.png)。Windows/Linux 仅交叉静态检查，未宣称真机验收；30 分钟长测及慢盘仍待补。
