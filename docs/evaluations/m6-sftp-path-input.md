# SFTP 有界路径输入与所选文件接线

状态：macOS/Linux 测试候选新增“远端目录/文件选择 → 本地源或目标输入 → 只读检查/完整审阅 → 明确开始”。SFTP 仍仅进入测试模块，默认发布入口关闭，完整 M6 不勾选。最终构建、真实回环、本地互操作及资源测量已完成；[证据一致性审计](m6-sftp-path-input-audit.json)核对当前源码、工具、清单及夹具 SHA，不把候选入口当作发布功能。

## 路径与输入所有权

[路径表单](../../src/workspace/transfer_paths.rs)只保留一个固定槽。上传输入本地源绝对路径（16 KiB）；未选中远端普通文件时可编辑新目标文件名（1024 字节），切换时可从本地 basename 建议初值。选中普通文件则冻结其完整原名字节作为目标。下载冻结所选普通文件的原路径和服务端属性 Version，只输入本地目标绝对路径（16 KiB）。属性缺少类型/大小/mtime 时明确拒绝，不能推测版本；后续补后台属性查询。符号链接不按普通文件处理。

本地输入为 UTF-8；无效 UTF-8 的本地文件选择器尚未实现。远端原名可含无效 UTF-8，操作继续使用原字节。编辑行中的控制、双向控制、零宽字符及反斜杠在显示中转义；只读远端标签沿用原模型的控制/双向字符及无效字节转义。实际路径不改写；NUL 拒绝，新目标名还拒绝斜杠、空名及点目录。局部选择按实际可见单元高亮，左右移动按 Unicode scalar 边界；完整字素编辑仍属于后续兼容性验收。输入代次使用 checked 更新；耗尽时关闭表单，不能在新布局继续沿用旧身份。

复用现有 InputContext/ProtectedInput：单次原生提交/预编辑仍最多 1023 字节，Cocoa 四槽及单次暂存上限不扩大。连续输入累计到字段上限；整段粘贴通过独立 PasteRequest，先取得字段上限额度再读取，不通过扩大原生提交暂存来容纳 16 KiB。每字段只允许一个在途读取，预算池、会话/配置代次、唯一表单编号、字段 view 都要匹配。切换字段、失焦、缩放/重排、取消、新表单或认证介入后，旧输入及粘贴不得应用，也不回落到终端。组合期间不移动/删除/换字段或接受迟到粘贴。

认证优先于路径表单。认证出现时立即停用表单、清组合/在途读取并更新 view；认证结束后用新 view 恢复。工作区持有 State 或 tick 临时移出 State 的两类路径都执行同样的停用，覆盖新挑战与后台任务认证恢复。

## 不在界面线程访问文件

上传“检查并审阅”只把路径交给原有后台 lstat 准备槽，成功才打开带固定源 Stamp 的完整审阅。下载直接把所选 Version 带入完整审阅，开始工作后仍按既有协议重新核对源。该页不创建目标文件；覆盖默认关闭，最终开始按钮仍要求完整信息已实际显示。无效本地路径或准入失败保留输入，等待明确修改或取消。

相对远端目录由后台 SFTP REALPATH 请求解析为一个绝对原名；要求服务端返回且只返回一个绝对名称，继续执行原有长度/NUL/预算校验。工作区随后采用 Listing.path，不能根据客户端 cwd 猜测远端路径。已经为绝对路径的目录不增加该请求。新增一次相对目录解析往返有延迟成本，未量化为零。结果截断/跳过名称时仍显示“不完整”。
