# M4 连接配置档与左栏入口

默认无配置档、无新增任务线程/子进程；`[connections.<id>]` 最多读取前 16 项。配置档支持本地 Shell 或 SSH 元数据；左栏“连接”显示类型、分组及名称，滚动后仍可点击末项。本地条目新建标签和独立 PTY，不改变现有会话，不把文件名或连接字段发送给现有 shell。SSH 条目此阶段仅显示，启动后端继续在 M5 接入；主题保存关联元数据，按窗格应用仍属 M8。

非敏感字段：标识 64 B、名称/分组/用户各 128 B、主机/明确别名 255 B、程序/密钥路径/本地目录各 4096 B；本地参数最多 32 项、单项 4096 B、合计 8192 B。主机不接受前导选项、通配符、URI 或 shell 命令；端口 1–65535。拒绝密码/私钥正文/任意 SSH 选项和未知字段，不回显错误字段值。只保存路径，不读密钥文件。本地路径按启动目录解释，不展开 ~ 或环境变量；SSH 路径语义将在后端接入时说明。

解析前申请 512 KiB `profiles-reserved` 保守工作额度，验证字段再分配，按实际 Vec/String/Path/Arc 结构容量保留，先销毁数据后归还。初次配置引导不提前固定全局预算，正式配置发布前先转移到初始化后的共享池；热重载直接复用共享池，旧配置和新配置重叠计费。额度不足只跳过新配置档，保留正在运行的会话。普通 TOML 树/解析器仍属于待覆盖的既有配置临时内存，不把这项完成称为完整账本。

不可变 Arc 共享配置档，Config 克隆及窗格切换不复制整张表。每个启动会话保留当时的配置快照，热重载不会把正在运行的会话改成新主机/程序；最多 8 个会话及当前配置共同限制旧表留存数，共享池限制总量。本地配置启动时另预留 128 KiB 临时额度，覆盖配置覆盖项、PTY 参数及平台转换的新增副本，启动失败保留旧会话。

独立分配探针排除既有 TOML 根树，最大字段模拟不实际执行虚构程序。全部实际峰值被准入覆盖，销毁后实际请求及额度归零；1000 次共享克隆零分配。计时分开无探针构建，五轮，转换+销毁 1000 次、克隆+销毁 100000 次：

|---|---:|---:|---:|---:|
| empty | 0 | 0 | 0.002 µs | 0 ns |

五组关闭功能的前后同负载：VT 130.2→130.4 MiB/s，整帧 3.028→3.044 ms，四窗格 630→625 µs，工作区输入 P95 209→292 ns、P99 1708→2250 ns。十组独立整帧 3.097→3.055 ms，单行 0.313→0.321 ms。差异在本机样本范围，不宣称零成本或 UI 原生呈现延迟验收；短纳秒计时不代表实际键盘到屏幕。

Debug/release 各 311 通过、13 忽略；三平台 all-target Clippy `-D warnings`。覆盖字段/数量/参数总长、无值回显、额度拒绝/迁移/共享释放，以及实际 Workspace/PTY 本地启动隔离、失败保留、热配置快照、目录根归属和短侧栏滚动末项。实际软件 Renderer [画面](../previews/m4-profiles.png) 已检查，缩短第三个标签为“本地”使默认宽度显示完整。
