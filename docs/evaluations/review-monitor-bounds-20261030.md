## 磁盘数据与拥有者

三个平台均采用有界原生枚举，不再创建 sysinfo 的设备、UUID、IO 统计或完整磁盘对象表。最多保留128个卷/挂载，单路径4096字节，总路径512 KiB。列表与路径缓冲通过 Tracked 在扩容前覆盖旧/新块，输出标签先计费再解码，独立票据随缓存标签留存；工作表销毁不会提前归还结果费用。

| 平台 | 输入与扫描边界 | 原生读取及失败规则 |
| --- | --- | --- |
| macOS | 原始挂载数最多128；按初次计数+1分配固定记录，写满/数量增长拒绝部分结果 | MNT_NOWAIT枚举、本地可写卷、可浏览属性、statfs容量；保留重要用途可用空间，0或不可用时回退普通可用空间 |
| Linux | `/proc/mounts`最多64 KiB+1个溢出探测字节，扫描最多4096行 | 一次解码转义，过滤原先不采样的伪/网络FS；statvfs只保留可写卷；溢出、读失败不发布前缀 |
| Windows | 最多128个卷，GUID缓冲1024 WCHAR、挂载路径MULTI_SZ最多8192 WCHAR，保留路径仍受4096字节限制 | 固定/可移动本地卷；忽略未挂载/只读/无介质卷；ERROR_MORE_DATA及枚举不完整显示未知，搜索句柄作用域关闭 |

最大可写外层卷按路径分量选择，`/data` 不遮挡 `/database`；只读父卷不再遮挡可写子卷。磁盘失败/超限返回未知，CPU/内存仍可用。回复记录本轮是否尝试刷新磁盘，即使读数未知也推进磁盘间隔，避免1 Hz重复枚举。缺失的磁盘历史绘制为问号（包括混合未知/已知值的压缩桶），不会伪造0%占用。预算拒绝仍暂停采样，保留历史，等待明确重试。

macOS只查询可浏览和容量两个标量属性；CF复制对象逐项释放，每个卷有autorelease池，排空后才归还64 KiB原生工作预留。这个预留是原生CF工作模型；**没有证明CF内部malloc或系统框架缓存的完整字节硬上限**。本轮证明的是调用方输入/容器/拥有者边界和费用生命周期，不把它扩大为完整native/RSS上界。

## 三平台进程路径

- 最多512个PID，保留前5条、每名字最多24个UTF-8字节。三个平台的工作预留统一为64 KiB；PID列表、下一份计数向量和名字都在取得费用后分配。源的旧向量由基础票据持有，新旧向量同时存活时工作票据覆盖重叠，输出由已有回复票据承接。
- Linux用固定8192字节getdents64缓冲，最多8192个目录项，避免libc DIR缓冲。每个`/proc/<pid>/stat`最多4096字节+溢出字节，有限短读/Interrupted重试；不读cmdline/environ/exe，不缓存stat FD，不调整RLIMIT。按最后右括号解析带空格/括号的comm；启动标识、CPU tick与RSS页数做溢出和单位校验。
- Windows只申请PROCESS_QUERY_LIMITED_INFORMATION，用固定计时/内存结构、最多4096 WCHAR路径；不分配整条UTF-8路径，只解码有界basename。查询句柄在所有返回路径关闭，创建时间隔离PID重用，退出/权限失败跳过并显示部分采样。[GetProcessMemoryInfo权限说明](https://learn.microsoft.com/en-us/windows/win32/api/psapi/nf-psapi-getprocessmemoryinfo) 支持该只读查询权限。
- macOS保留上批固定libproc记录及Mach timebase换算，改为共享有界显示逻辑。无法读取/预算不足/截断均显示部分或不可用，不把缺失项当完整全机进程表。
