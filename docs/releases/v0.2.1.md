# congminal v0.2.1

修复 Windows 中 NakuruMusic 等程序仍显示字符色块的问题。

ConPTY 在子程序未开启 VT 输入时会把 Kitty APC 应答中的 ESC 当作 Alt 按键处理。v0.2.0 的手写测试预先开启了 VT 输入，漏掉了真实应用先探测、后初始化 TUI 的路径。现通过 ConPTY 原生 Unicode 输入记录保留 APC 应答中的 ESC，普通查询、键盘输入和粘贴保持原路径。

新增真实 `ratatui-image 11.0.6` 自动探测及 crossterm 初始化回归：不强制选择 Kitty、不预设控制台模式，直接启动和 Windows 的 PowerShell 7 启动均核对完整图片的 65536 个 RGBA 字节。

应答适配只在 Windows 现代 ConPTY 收到 APC 应答时执行，输入最多 4096 B，临时编码缓冲固定 16 KiB，写入仍受原有队列预算与整笔拒绝规则约束；没有新增生产依赖、常驻线程或缓存。三平台图标、静态图片能力和原有图片内存边界沿用 v0.2.0。

升级后请退出所有旧 congminal 窗口并重新打开，再重新启动 NakuruMusic；协议在 Nakuru 启动时探测一次。Windows 保留完整安装目录的 `conpty.dll` 与 `x64/OpenConsole.exe`。
