# congminal v0.2.2

- Windows 本地终端默认在用户主目录 `%USERPROFILE%` 启动，从 Scoop、快捷方式或命令行打开均不再默认停在安装目录。显式 `shell.working-directory` 和本地连接配置档的目录优先；全局 `shell.working-directory` 支持 `~` 展开到主目录，`.` 保留启动目录。主目录变量缺失、格式不合法或超长时继承启动目录。
- 三平台原生窗口标题固定为 `congminal`，shell 的 OSC 标题保留在窗格/标签页中，不再将 `pwsh.exe` 路径写到窗口标题栏。减少标题切换时的字符串复制与原生窗口更新。
- 新增 Windows 原生 GUI 回归：从安装目录启动，检查默认主目录、含空格/中文的显式目录、`.` 继承目录，以及 shell 覆盖标题后窗口名称的稳定性。保留真实图片库自动探测和整图传输回归。

不增加生产依赖、常驻线程或后台轮询。Windows 主目录通过有界环境查询读取，最多 4096 个 UTF-16 单元；只在构建启动配置时处理，不进入绘制热路径。升级后退出旧窗口并重新打开。
