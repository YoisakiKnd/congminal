# congminal v0.1.0

首个正式版本将终端工作区与 SSH/SFTP、Git、监控、通知和外观设置整合到默认构建。安装与快捷键见根目录 README；实际验收记录见 `docs/evaluations/v0.1.0/README.md`。

## 安装包

- macOS 通用 `.app`：Apple 芯片与 Intel，macOS 11+，临时签名，尚未公证。
- Windows x86_64：Windows 10 1809+，运行 `congminal.exe`。
- Linux x86_64：需要 X11/XWayland 和构建包所需的 glibc。
- 三平台默认附带 `congminal-ssh-helper`，请与主程序一起保留。包旁提供 SHA256 文件。

## 主要功能

- 多标签、横纵分屏、左右侧栏、历史搜索、链接和可选布局恢复。
- 系统 OpenSSH 终端连接、配置别名、跳板和端口转发。
- 内置 SFTP v3 文件界面及任务管理，连接、加密和认证复用系统 OpenSSH；无需外部交互式 `sftp` 程序。
- 文件和目录上传/下载、续传、重命名、创建、删除、临时副本打开与显式编辑上传。默认下载不覆盖，覆盖须确认；失败保留可恢复暂存。
- 本地 Git 状态、diff、历史、分支和显式写操作；远程 Git 只读。
- 原生 CPU、内存、磁盘和进程监控；可配置命令、传输、Git、SSH 与监控通知。
- 主题、字体回退、编程连字、彩色 emoji、透明度和光标设置。

## 资源与兼容性

SFTP 沿用 2 工作槽、64 等待槽和 16 MiB 子池额度，入口未点击前不建立池、线程或网络连接。目录扫描最多 2000 文件、512 目录、16 层、8 GiB，每帧最多提交 4 个文件；目录页、结果和票据按存活期保留额度。符号链接与特殊文件不递归跟随，截断预览禁止整树删除。

Windows 使用用户私有 DACL 的认证票据/命名管道和句柄绑定的本地暂存/发布。临时副本目录在后台创建；文件打开使用原生系统接口。监控移除 `sysinfo`，默认 Unix Rust 运行时依赖仅为 `libc` 系统 FFI，Windows 无额外 Rust 运行依赖。

资源额度不等于进程 RSS 硬限制，系统库、线程栈、内核和外部 SSH/编辑器成本另计。SFTP 客户端基线为 OpenSSH 8.7+，Windows 还需支持 askpass 的移植版。每次操作使用独立连接，建议密钥和 agent；密码可能重复提示。

Linux 尚无原生 Wayland 后端；不同平台输入法、复杂文字排版和终端扩展的覆盖范围见 README。macOS 包未公证。真实测试范围、失败修复和性能原始证据持续记录于正式版验收目录，不将编译或单元通过等同于所有桌面环境验收。
