# congminal v0.2.0

三平台新增 Kitty 静态图像支持与角色终端应用图标；修复 Windows 默认 shell 和终端标识。

- Kitty 能力查询、直接 RGB/RGBA/PNG 传输、zlib、分块、普通放置及 Unicode 占位符、32 位图片 ID、裁剪、删除和安静模式。验证 NakuruMusic 使用的 ratatui-image 11.0.6 实际输出。
- 图片数据按容量纳入共享预算：单图最多 4 Mi 像素，缓存至多 16 张 / 16 MiB，放置最多 32 项；分块输入最多 16 MiB、每条 APC 5120 B，超限拒绝、旧图回收。不读取协议指定的本地文件或共享内存，不支持动画及相对放置。
- 字符格子仍为 20 B，图片放置色使用不可重定向的有界索引；直接暖绘制复用缓冲。
- Windows 包带固定微软 ConPTY 1.25.260930003，解决系统旧 ConPTY 丢弃图像 APC 的问题。保留 conpty.dll、x64/OpenConsole.exe、认证 helper 及其许可文件，不要只复制主 EXE。加载仅从程序目录进行，无运行时下载。
- Windows 未显式配置 shell 时优先固定本地位置的 PowerShell 7，再 Windows PowerShell，最后 COMSPEC。TERM/COLORTERM/TERM_PROGRAM 与 Unix 一致；显式配置优先。
- 角色终端图标接入 macOS ICNS、Windows EXE/窗口和 Linux 窗口/XDG 桌面。Linux 解压包提供 install-linux.sh，安装到当前用户目录。
