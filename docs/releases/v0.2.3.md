# congminal v0.2.3

macOS、Windows、Linux 统一以下默认行为：

- 本地终端默认进入用户主目录；显式工作目录优先，`~` 指向主目录，`.` 保留启动目录。本地连接配置档使用相同规则。
- 原生窗口标题固定为 `congminal`；shell 和程序上报的标题继续显示在窗格/标签中。
- 保留 Kitty 静态图片、真实图片库自动探测和完整图像传输回归。

精简文档：当前目录保留用户和开发所需入口、正式版本说明及最新验收；1,165 个历史文件经 Git 内容哈希核对后固定归档到 `v0.2.2`，原始证据和旧标签可恢复，不重写历史数据。

不增加生产依赖、常驻线程或定时任务。主目录候选有明确长度限制；窗口标题更新减少字符串复制和原生调用。升级后退出旧窗口并重新打开。
