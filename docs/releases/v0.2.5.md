# congminal v0.2.5

提升终端输出、滚动和画面提交性能，减少历史记录内存：

- 解析器批量处理可打印 ASCII 并缓存字素状态，大量输出时吞吐提高约 2～10 倍（ASCII 滚动输出 66 → 200 MiB/s，2027 字素模式 19 → 192 MiB/s，彩色输出 68 → 138 MiB/s，中文 74 → 92 MiB/s）。
- 历史记录改为可还原的紧凑行，记录有效列宽、整数颜色和宽字符位图。1 万行 ASCII 历史从 40.1 MB 降到 1.53 MB；长彩色行之后的短行不再长期占用长行空间。
- 滚动时平移已有画面，只重画新露出的行；回看历史时同样适用。画面未变时跳过绘制，只改一行时只重画这一行。滚动一行的帧从 5.21 ms 降到 1.69 ms。
- PTY 输出缓冲按容量分级复用；窗格直接绘制到工作区画布，不再先画到单独缓冲区再复制。
- macOS 减少画面格式转换，复用原生快照，快照池最多 1 张整帧。
- 窗口最小化或被完全遮挡时停止绘制和光标闪烁，终端输出继续解析；同时清空快照池，并提示系统分配器归还内存（最少间隔 5 秒）。
- Linux X11 优先通过共享内存（MIT-SHM）提交画面，大量输出时 X 服务器 CPU 降低约 2/3；缺少 libXext 或远程显示时自动退回原方式。X11 和 Windows 只提交有变化的区域。

不新增生产依赖、常驻线程或定时任务；libXext 运行时加载，不是编译期依赖。去掉字形缓存中的 unsafe 地址表。

以上数字为 Linux x86_64 本机 3 轮中位数，绘制时间不含系统合成。macOS 快照池和 Windows 分段提交只经过编译与 CI 冒烟检查。升级后退出旧窗口并重新打开。许可证为 GPL-3.0-only。
