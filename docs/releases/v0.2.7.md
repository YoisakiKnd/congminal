# congminal v0.2.7

修复版本：macOS 上从 Dock、Finder 或启动台打开 congminal 时，找不到 `brew` 和用 Homebrew 安装的命令。

- 原因：图形界面启动的程序只继承 `/usr/bin:/bin:/usr/sbin:/sbin`，Homebrew 的路径写在 `/etc/zprofile`（path_helper）和 `~/.zprofile` 里，zsh 只有作为登录 shell 才读；之前 congminal 启动的不是登录 shell。
- 现在 macOS 上没写 `shell.args` 时按登录 shell 启动，与 Terminal.app、iTerm2、Ghostty 相同。写了参数的（`-c`、SSH 会话等）原样执行；Linux 不变。
- 没有 `$SHELL` 时先用用户数据库里登记的 shell，最后才是 `/bin/sh`。

v0.2.6 上可以在配置里写 `[shell]` `args = ["-l"]` 临时解决。升级后退出旧窗口并重新打开。许可证为 GPL-3.0-only。
