# congminal v0.2.4

改善 Windows、macOS、Linux 共用的终端工作区界面：

- 侧栏增加留白和分区，页签用强调色与下划线，按钮、选中行和说明文字采用不同样式；随深浅主题切换。
- 两侧栏同时打开时压缩侧栏宽度，尽量保留 40 列终端空间；放不下的侧栏自动隐藏。统一页签绘制、点击和拖动的宽度。
- 空连接页提供 SSH 配置步骤、复制示例和重新读取配置操作。复制使用原有有界剪贴板通道，不把配置文本发送到终端。
- Git 操作按最多三列排列。非仓库、缺少 Git、未获得远端目录等状态分别给出下一步说明，并隐藏不可用的写操作。
- 状态页分开显示会话、工具环境和通知，去掉把内部线程显示为用户任务的文案；通知点击位置与新布局保持一致。
- 监控使用直接绘制的趋势条，拆开内存、磁盘和网速数字，保留缺失读数、暂停、过期及远端延迟提示。
- 三端默认鼠标指针统一为系统箭头，修复侧栏、按钮与终端都显示 I 形指针的问题。

不新增生产依赖、字体、图表缓存、后台线程或动画计时器。工具探测复用配置缓存，最多保存 4 项；引导文字有字符、段落和可见行限制，趋势图直接遍历已有定长历史，最多绘制 48 个桶。保留主目录启动、固定窗口标题、Kitty 图片和 SFTP 能力。

本机验证：929 项测试通过，真实窗口检查深浅主题、窄窗口、Git 和监控页。30×24 格侧栏预热后绘制平均约 39 μs，连续 1000 次绘制跟踪额度保持不变。现有 Neovim 配置（69 个插件、采样时加载 61 个）打开万行 Lua 文件，4 次测试的就绪后软件画面更新为 0.83～0.89 秒，终端软件绘制 P95 为 1.39 ms。以上仅为本机测量，绘制时间不包含系统合成或端到端按键延迟。

升级后退出旧窗口并重新打开。许可证为 GPL-3.0-only，安装包保留全部许可、helper 和 Windows ConPTY 配套文件。
