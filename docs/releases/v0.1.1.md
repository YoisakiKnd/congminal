# congminal v0.1.1

许可证与安装包补全版本；终端、SSH/SFTP、Git、监控和通知功能沿用 v0.1.0。

- 原创源码采用 GNU GPL v3，仅第 3 版（SPDX: GPL-3.0-only），新增完整 LICENSE 和项目 NOTICE；声明也覆盖原创 v0.1.0 代码。
- macOS、Windows、Linux 安装包全部附带项目许可、版权与第三方许可；Terminus Font 仍使用 SIL OFL 1.1。
- Cargo 元数据声明 GPL-3.0-only，发布说明按实际版本选择。
- 对应源码与构建脚本随本次 Release 的源码归档和 v0.1.1 标签公开：<https://github.com/YoisakiKnd/congminal/tree/v0.1.1>。

本次未新增运行时依赖、线程、内存池或网络后台任务。v0.1.0 资产及校验和保持不变。

macOS 包仍为临时签名且尚未公证；Linux 使用 X11/XWayland。SFTP 默认包含认证 helper，连接依赖支持 askpass 的 OpenSSH 8.7+。安装要求与快捷键见 README。
