# 路线图

当前发布范围以 [README](../README.md)、[配置参考](configuration.md) 和 [发布记录](releases/README.md) 为准。历史阶段计划和交接已归档，不再以旧复选框数量表示当前完成度。

## 已交付的主线

- 本地终端、多标签、横纵分屏、左右侧栏、历史搜索、字体回退与主题。
- 系统 OpenSSH 连接、跳板和转发；内置有界 SFTP v3 操作、认证和临时打开流程。
- Git、状态监控、命令集成和通知入口。
- 三平台 Kitty 静态图片及角色应用图标，Windows 现代 ConPTY 和 PowerShell 默认值。
- 用户主目录与窗口标题统一行为；显式工作目录保持优先。

## 本次收尾

- 三平台统一默认主目录；`~` 和明确路径按配置使用，`.` 继承启动目录。
- 窗口标题统一 `congminal`，标签保留程序上报的标题。
- 当前文档只保留使用、配置、资源边界、策略、发布说明和最新验收；历史资料固定归档。

## 后续工作与待验收范围

- Kitty 动画、文件/共享内存传输、相对放置和其他扩展按实际需求评估，不标为已支持。
- 原生 Wayland、GPU 渲染、CFF/CFF2 与可变字体另行立项；当前后端和字体范围仍以已实现能力为准。
- SSH 连接复用、完整跨平台模糊效果仍待实现和评估；可选库后端不替代当前正式默认方案。
- 扩大三平台输入法、外部剪贴板、浏览器和编辑器真机交互覆盖；自动化通过不代表所有桌面已验收。
- 完善覆盖率导向模糊测试和持续长测；补 Windows 新 ConPTY 多会话及长时间资源曲线。
- 持续核对资源账本覆盖、复杂文字、真实输入到呈现延迟和旧计划中的未验收项。原始详细清单保留在 [历史路线图](https://github.com/YoisakiKnd/congminal/blob/v0.2.2/docs/roadmap.md)。

新增依赖、扩大缓存或并发前，遵循 [依赖策略](dependency-policy.md)。未测量的场景保持“未验证”，不使用旧报告或交叉编译代替新验收。
