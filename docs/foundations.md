# 第一批底层加固：I/O、资源边界和回归验证

本批保持零第三方运行依赖，优先保证持续输出时可交互、队列可关闭、字体热加载能释放资源，以及外部数据解析有预算。协议、完整 Unicode 分段、动态 DPI 和字体格式扩展仍按后续阶段推进。

## 已实现

- PTY 输出使用有界队列，满时读线程等待；暂停读取会把背压传递给子进程，正常运行时不截断字节流。
- PTY 输入由独立写线程发送，支持短写、Interrupted 和 Unix 非阻塞 PTY；排队和正在写入的内容共同计入预算。队列满时整笔拒绝，终端内显示提示，不截断粘贴标记。
- 主线程在原生事件处理后消费输出，每轮同时检查字节和时间预算；积压工作通过事件循环截止时间续跑，不连续投递原生唤醒事件。
- 进程退出与输出 EOF 分开处理，排空输出后再退出。Unix 用 CLOEXEC 启动通道回传系统调用错误，等待线程保存退出状态，并在回收 PID 时与关闭操作同步。读线程空闲时阻塞在 poll，进程退出时由专用通道唤醒。
- 字体映射与表切片采用共享所有权，最后一个使用者释放时解除映射；弱缓存复用仍在使用的字体，热加载不永久泄漏旧映射。
- 字形和整形缓存按字节、条目数限制，采用 FIFO 淘汰；常用历史行继续复用已有存储。
- 回滚历史按行数和字节双重限制；宽度重排边生成边淘汰，避免先分配全部宽行再丢弃。
- 修复宽字符在局部擦除、插入、删除和裁剪后留下孤立半格的问题。
- PNG 校验 CRC、块边界和关键结构；zlib 必须有有效校验和。解压前计算精确扫描行预算，并限制每次输出扩容。图像缩放只保留一行浮点中间值。
- TrueType 复合轮廓有深度、访问次数和线段预算；GSUB 有预计算和应用工作量预算，morx 有链/子表边界；光栅化和彩色图层有像素预算。
- 配置读取大小、语法条目、递归深度、字体列表，以及字号/缩放环境变量均有限制。

## 当前预算

| 子系统 | 上限与超限行为 |
|---|---|
| PTY 输出队列 | 1 MiB、1024 个数据块；满时暂停读取，另有固定大小的读/解析批次 |
| PTY 输入 | 8 MiB、1024 笔；包含正在发送的一笔；新输入整笔拒绝并提示 |
| 单轮输出解析 | 至多 128 KiB / 约 2 ms；每 1 KiB 检查一次时间 |
| 回滚历史 | 配置行数上限与 64 MiB 行存储预算取先达到者；淘汰最旧内容 |
| 主/备用屏幕 | 每个网格最多 1,048,576 格；最多 4096 列、2048 行 |
| 帧缓冲 | 最多 64M 像素（256 MiB），单边最多 16384；拒绝超限或分配失败 |
| 字形缓存 | 普通 16 MiB、组合符 4 MiB、索引字形 4 MiB、emoji 簇 8 MiB |
| 整形缓存 | 常规、粗体各 1 MiB；输入超过 1024 字节时跳过编程连字 |
| 字体文件 | 单文件最多 512 MiB；映射失败时按声明长度有界读取 |
| PNG | 文件/压缩数据最多 32 MiB、总像素最多 4M、单边最多 16384 |
| 缩放/光栅化/COLR | 单个输出字形最多 1M 像素；COLR 最多 128 层，源位图像素总和另有限制 |
| 配置 | 文件最多 1 MiB、值嵌套最多 32 层、键路径最多 32 段、语法条目预算 4096、字体列表最多 16 个 |

这些是各子系统的预算，不是整个进程 RSS 上限：系统窗口表面、字体映射、容器元数据、输入字符串和重排临时对象也占空间。历史超出字节预算时，实际可回滚行数会少于配置值。

2 ms 是合作式调度目标：检查发生在解析片段之间，单条复杂终端指令及渲染工作不受严格实时截止时间保证。输入队列接纳是整笔原子的，子进程在发送中途退出仍可能只接收到部分内容。

## 验证

```sh
cargo fmt --all -- --check
cargo clippy --offline --all-targets -- -D warnings
cargo test --offline
cargo test --offline --release bench_ -- --ignored --nocapture --test-threads=1
```

新增覆盖包括：

- 同一字节流在每一个位置分块、逐字节输入时，网格、模式、标题和应答一致。
- 宽字符编辑与缩放不变量、固定种子的畸形字节流、历史加宽时的预算和光标保持。
- 独立构造的小型 TrueType 字体，从解析到光栅化的固定结果；字体截断和逐字节变异。
- 队列背压、关闭解除等待、在途字节预留、短写和写入错误。
- Unix 真实 PTY：2 MiB 输出与尾部文本保持完整、退出码保持；子进程不读取输入时调用线程不阻塞；启动路径和工作目录错误回传。
- 字体映射复用、表切片延长所有权、最后引用释放。
- PNG 每个截断位置、错误 CRC、超大尺寸，DEFLATE 字面量/存储块/回溯复制的预算。
- 配置深层嵌套、超大文件，帧缓冲尺寸溢出和超限拒绝。

macOS 已运行上述测试及窗口启动/2 MiB 输出/退出冒烟验证。Linux、Windows 已做交叉编译与 Clippy 检查；运行时验证依赖现有三平台 CI，不能用交叉检查替代。

可选的真实编程字体和彩色字体集成测试仍受本机字体安装影响；新增的固定字体测试不依赖这些安装。持续 libFuzzer、完整字体格式语料库和各平台长时间压力测试留作下一步。

## 本机性能对照（2026-10-20）

对照提交 `626cc44` 与本批工作区，release 编译后交替执行三次，单线程运行基准并取中位数。
使用同一字体 Maple Mono NF CN（30px），渲染尺寸均为 3616×2416、200×60 格。
解析负载为一百万行带 SGR、中文和组合音标的文本，按 1 KiB 分块输入。

| 指标 | 改动前 | 改动后 |
|---|---:|---:|
| VT 解析 | 129.6 MiB/s | 130.0 MiB/s |
| 整屏重绘 | 2.96 ms/帧 | 3.01 ms/帧 |
| 单行更新 | 0.310 ms/帧 | 0.299 ms/帧 |

这些数据只代表本机和该负载，差异接近测量波动，不作为普遍提速结论。测试过程中定位并消除了历史行回收的多余扫描和重复记账，保留了有界缓冲后的稳态吞吐。该解析基准不包含窗口事件调度和 PTY 传输；完整链路另做真实 PTY 和窗口冒烟验证。
