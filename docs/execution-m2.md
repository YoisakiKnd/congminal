# M2 执行记录：搜索与链接

日期：2026-10-20。对照基线为本轮开始时包含 M1 实现的完整工作树；未重置或提交之前的改动。

## 本轮目标

落实 [路线图 M2](roadmap.md)：中文纯文本搜索、软换行与格子映射、有界扫描及取消失效、匹配导航和高亮，以及 OSC 8/可见 URL 的悬停、复制和显式打开。

## 已实现

- `src/search.rs`：直接读取终端行的流式 KMP，不复制整份历史或超长逻辑行。查询最多 1 KiB；每轮至多 32768 个字符/行界步骤或约 2 ms，每 128 步检查时间。
- 最多缓存 1024 个命中范围。到达容量暂停扫描，数量显示 `+`；继续向后导航时淘汰一部分旧缓存并发现后续命中。向前越过缓存边界时分片重扫并保留目标前的窗口，支持首尾循环。扫描未完成显示 `…`，不把部分计数当作全量总数。
- `src/text.rs`：将软换行拼接为连续文本，跳过宽字符占位格和宽字换行留下的填充格；基字符、组合符和变体选择符映射回实际格子范围。硬换行断开匹配。首版精确区分大小写，不做 Unicode 规范化或正则匹配。
- 输出流更新时保留已扫描的稳定历史，从可变屏幕边界检查点重扫；历史淘汰会清理过期坐标。重排、清历史、复位和主/备用屏幕切换通过代次使旧结果失效。查询修改立即替换旧扫描，关闭立即释放结果和扫描状态。
- `src/ui.rs` 与渲染器：底部搜索栏、命中/当前命中高亮、输入法预编辑及候选框坐标；沿用逐行指纹和脏区域绘制。搜索栏覆盖最后一行，不改变 PTY 行列；关闭后恢复终端显示。搜索输入、提交和粘贴不发送给 shell。
- `src/links.rs`：OSC 8 目标随字符属性经过滚动、编辑和重排；SGR 复位不关闭链接。扩展属性利用原有布局空间，单元格仍为 20 B，未增加每格存储。
- 显式链接优先于可见文本识别；可见 HTTP/HTTPS URL 按鼠标所在词有界识别，支持跨软换行和常见末尾标点处理。命中真实目标在底栏显示，悬停下划线和地址更新均参与脏行判定。
- 只有用户显式动作会打开或复制链接。终端输出、OSC 8、悬停和普通选择不会启动浏览器。显式链接手势消费对应按下/抬起，普通鼠标事件维持原有上报和选区行为。
- `src/launcher.rs`：通过结构化参数调用桌面打开接口，不拼接 shell 命令。按需复用一个有界工作线程，忙时不积压点击。macOS 使用 `/usr/bin/open`；Linux 使用 `gio open`，缺失时显示错误；Windows 按需从系统目录加载 ShellExecuteW，未点击时不增加 shell32 的显式加载依赖。

## 使用

| 操作 | 默认方式 |
|---|---|
| 打开搜索 | macOS Cmd+F；Windows/Linux Ctrl+Shift+F |
| 后一项 / 前一项 | 搜索栏内 Enter / Shift+Enter；也可 F3 / Shift+F3 |
| 编辑查询 | 左右、Home/End、退格、Delete；支持输入法提交、粘贴 |
| 复制查询 | 原有复制快捷键；不向 shell 发送 Ctrl+C |
| 退出搜索 | Esc，随后普通输入回到终端 |
| 打开链接 | macOS Cmd+单击；Windows/Linux Ctrl+单击 |
| 复制链接目标 | 上述组合再加 Shift |
| 自定义动作 | `[keybindings]` 的 `search`、`search-next`、`search-previous`、`open-link`、`copy-link` |

普通鼠标上报模式仍生效；只有命中链接的显式修饰键手势由终端消费，正在进行的拖动/上报不会中途改成打开动作。链接地址栏是状态显示，不是另一条可点击的链接。

无窗口帧缓冲绘制预览：[中文搜索与命中高亮](previews/m2-search.png)。这验证了实际渲染输出，不代替原生窗口/输入法交互验收。

## 资源和失效边界

| 项目 | 边界与行为 |
|---|---|
| 查询 / 预编辑 | 各最多 1 KiB；仅扫描有限输入前缀，超限不继续接纳字符；预编辑不会保留超大原始事件容量 |
| 结果窗口 | 至多 1024 范围，不保留历史文本副本；更多命中按导航发现 |
| KMP 与坐标窗口 | 长度随查询字符数，最多 1024；保留一个可变尾部检查点 |
| URL | 仅 HTTP/HTTPS、最多 2048 B；控制字符、空白和反斜杠目标拒绝 |
| OSC 输入 | 仍至多 4096 B；溢出、取消或非法控制字符丢弃，不把截断前缀注册为链接 |
| 显式目标池 | 至多 1024 条且 URL 正文总和不超过 1 MiB；超限淘汰最旧目标，旧字符不再可打开 |
| 字符属性 ID | 21 位、单次终端生命周期内不复用；耗尽后停止注册，复位会连同全部网格重建 |
| 历史淘汰 | 链接段关闭时记录保守的文档末端水位；旧水位淘汰后清理，仍受目标池双上限约束 |
| 悬停识别 | 仅扫描命中词与有限标签范围；可见词超过 2 KiB 不识别，不建立全历史 URL 索引 |
| 桌面打开 | 最多一个在途请求；Unix helper 5 秒超时/取消后回收，输出不进入无界缓冲；Windows 系统调用合作式取消，不在 UI 上等待 |

资源快照增加搜索状态与链接池负载。统计与 RSS 不等价，浏览器内存也不计入终端的受管堆预算。首次打开会创建工作线程并调用系统桌面服务/浏览器，不能声称零开销；详见 [评估记录](evaluations/m2.md)。
